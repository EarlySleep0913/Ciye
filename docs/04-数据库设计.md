# 数据库设计

## 概述

- 数据库：SQLite
- 模式：WAL（Write-Ahead Logging）
- 连接策略：线程本地连接（threading.local）
- 字符编码：UTF-8

## 表结构

### 1. users — 用户表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO_INCREMENT | 用户ID |
| username | TEXT | UNIQUE, NOT NULL | 用户名 |
| password_hash | TEXT | NOT NULL | SHA256 + 固定盐 哈希 |
| role | TEXT | NOT NULL, DEFAULT 'user' | 角色：admin / user |
| created_at | TEXT | NOT NULL | 创建时间 ISO 格式 |

### 2. sessions — 会话表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| token | TEXT | PK | UUID4 会话令牌 |
| user_id | INTEGER | NOT NULL, FK→users | 用户ID |
| created_at | TEXT | NOT NULL | 创建时间 |

### 3. books — 词书表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO_INCREMENT | 词书ID |
| user_id | INTEGER | NOT NULL | 所属用户 |
| name | TEXT | NOT NULL | 词书名称 |
| is_public | INTEGER | DEFAULT 0 | 是否公开 |
| created_at | TEXT | NOT NULL | 创建时间 |

### 4. words — 单词表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO_INCREMENT | 单词ID |
| book_id | INTEGER | NOT NULL, FK→books | 所属词书 |
| word | TEXT | NOT NULL | 英文单词 |
| translation | TEXT | | 中文释义 |
| definition | TEXT | | 英文释义 |
| phonetic | TEXT | | 音标 |
| example | TEXT | | 例句 |
| audio_url | TEXT | | 发音链接 |
| image_url | TEXT | | 配图链接 |
| created_at | TEXT | NOT NULL | 创建时间 |

**约束**：UNIQUE(book_id, word) — 同一词书内单词唯一

### 5. progress — 学习进度表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | INTEGER | PK, FK→users | 用户ID |
| word_id | INTEGER | PK, FK→words | 单词ID |
| status | TEXT | DEFAULT 'new' | 状态：new / learning / mastered |
| familiarity | INTEGER | DEFAULT 0 | 熟悉度 0-10（旧版） |
| memory_strength | REAL | DEFAULT 1.0 | 记忆强度 S |
| attempts | INTEGER | DEFAULT 0 | 尝试次数 |
| correct | INTEGER | DEFAULT 0 | 正确次数 |
| last_seen | TEXT | | 上次学习时间 |
| due_date | TEXT | | 下次复习日期 |
| is_favorite | INTEGER | DEFAULT 0 | 是否收藏 |
| is_wrong | INTEGER | DEFAULT 0 | 是否错词 |

**状态流转**：
```
new → learning (任意反馈)
new → mastered (反馈为 easy)
learning → mastered (反馈为 easy)
```

### 6. events — 学习事件表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO_INCREMENT | 事件ID |
| user_id | INTEGER | NOT NULL | 用户ID |
| word_id | INTEGER | FK→words | 单词ID |
| action | TEXT | NOT NULL | 操作：forgot/vague/known/easy |
| created_at | TEXT | NOT NULL | 时间 |

### 7. settings — 设置表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | INTEGER | PK, DEFAULT 0 | 用户ID（0=全局） |
| key | TEXT | PK | 设置键 |
| value | TEXT | | 设置值 |

**关键设置项**：

| Key | 范围 | 说明 |
|-----|------|------|
| active_book_id | 用户 | 当前学习的词书ID |
| daily_new_limit | 用户 | 每日新词数量 |
| date_offset | 全局 | 日期偏移（测试用） |
| pexels_api_key | 全局 | Pexels API Key |
| ai_api_url | 全局 | AI API 地址 |
| ai_api_key | 全局 | AI API Key |
| ai_model | 全局 | AI 模型名 |
| ai_api_format | 全局 | API 格式：openai / anthropic |

### 8. daily_session — 每日学习会话

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | INTEGER | PK | 用户ID |
| date | TEXT | PK | 虚拟日期 |
| book_id | INTEGER | PK | 词书ID |
| word_ids | TEXT | NOT NULL | JSON 数组：今日队列单词ID |
| studied_ids | TEXT | DEFAULT '[]' | JSON 数组：已学单词ID |
| created_at | TEXT | NOT NULL | 创建时间 |

### 9. pdf_words — PDF 词表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO_INCREMENT | ID |
| day | INTEGER | NOT NULL | 天数 |
| position | INTEGER | NOT NULL | 位置 |
| word | TEXT | NOT NULL | 单词 |
| translation | TEXT | NOT NULL | 翻译 |
| source | TEXT | DEFAULT 'cet4_pdf' | 来源 |

### 10. pdf_word_marks — PDF 词表标记

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | INTEGER | PK | 用户ID |
| word_id | INTEGER | PK, FK→pdf_words | 单词ID |
| crossed | INTEGER | DEFAULT 0 | 是否标记 |
| updated_at | TEXT | NOT NULL | 更新时间 |

### 11. ai_chats — AI 对话历史

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | INTEGER | PK | 用户ID |
| messages | TEXT | DEFAULT '[]' | JSON 数组：对话消息 |
| updated_at | TEXT | NOT NULL | 更新时间 |

## 索引

```sql
CREATE INDEX idx_books_user ON books(user_id);
CREATE INDEX idx_progress_due ON progress(user_id, status, due_date);
CREATE INDEX idx_words_book_word ON words(book_id, word);
CREATE INDEX idx_events_user_date ON events(user_id, created_at);
CREATE INDEX idx_pdf_words_source ON pdf_words(source, day, position);
CREATE INDEX idx_sessions_user ON sessions(user_id);
```

---

## ER 关系

```
users 1──N books
books 1──N words
users 1──N progress N──1 words
users 1──N events
users 1──1 daily_session (per date)
users 1──1 ai_chats
users 1──N pdf_word_marks N──1 pdf_words
```

## 数据隔离策略

所有用户数据表通过 `user_id` 字段隔离：
- 查询时自动添加 `WHERE user_id = ?` 过滤
- 新用户注册时自动创建空的 progress 记录（懒初始化）
- 全局设置使用 `user_id = 0`
