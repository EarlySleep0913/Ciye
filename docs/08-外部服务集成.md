# 外部服务集成

## 1. Free Dictionary API

- **地址**：`https://api.dictionaryapi.dev/api/v2/entries/en/{word}`
- **认证**：无
- **用途**：获取单词的音标、英文释义、例句、发音音频
- **调用时机**：单词查询（`/api/lookup`）时懒加载
- **错误处理**：404 时跳过，不影响其他数据源

### 返回数据映射

| API 字段 | 系统字段 | 说明 |
|----------|----------|------|
| phonetic | phonetic | 音标 |
| meanings[].definitions[0].definition | definition | 英文释义 |
| meanings[].definitions[0].example | example | 例句 |
| phonetics[].audio | audio_url | 发音链接 |

## 2. ECDICT（本地词典）

- **文件**：`data/ecdict.db`（810MB SQLite）
- **认证**：无（本地文件）
- **用途**：获取中文释义
- **调用时机**：单词查询时优先使用

### 查询逻辑

```sql
SELECT sw, phonetic, translation, definition, exchange
FROM stardict
WHERE sw = ? COLLATE NOCASE
```

### 数据交换格式

ECDICT 的 `exchange` 字段包含：
- `p:` — 复数/过去式
- `d:` — 比较级
- `t:` — 最高级
- `i:` — 现在分词
- `3:` — 第三人称单数
- `r:` — 副词
- `1:` — lemma

## 3. Pexels API

- **地址**：`https://api.pexels.com/v1/search`
- **认证**：API Key（Header: `Authorization: {key}`）
- **用途**：为单词搜索配图
- **配置**：在设置页面输入 API Key
- **状态缓存**：5 分钟缓存可用状态

### 调用参数

```
GET /v1/search?query={word}&per_page=1
```

### 状态检测

```python
# 5分钟缓存
if now - last_check < 300:
    return cached_status
```

## 4. SiliconFlow AI API

- **地址**：`https://api.siliconflow.cn`（可配置）
- **认证**：API Key
- **用途**：AI 对话、词书生成、AI 助手
- **支持格式**：OpenAI 兼容 / Anthropic Messages

### 使用的模型

| 模型 | 用途 |
|------|------|
| Pro/moonshotai/Kimi-K2.6 | 词书导入解析 |
| deepseek-ai/DeepSeek-V4-Flash | AI 助手对话 |

### 请求格式

**OpenAI**：
```
POST /v1/chat/completions
Authorization: Bearer {key}
```

**Anthropic**：
```
POST /v1/messages
x-api-key: {key}
anthropic-version: 2023-06-01
```

```

    ↓
```

## 错误处理策略

| 服务 | 超时 | 重试 | 降级 |
|------|------|------|------|
| Free Dictionary | 5s | 0 | 跳过，显示"暂无" |
| ECDICT | 本地 | 0 | 跳过 |
| Pexels | 10s | 0 | 显示"暂无配图" |
| AI API | 60-120s | 0 | 报错提示 |
| 前端请求 | 15s（AI 120s） | 3次 | 报错 |
