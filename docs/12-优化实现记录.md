# CiYe Pro 优化实现记录

本文档记录 `E:\Codex\Ciye_pro` 相对原 `ciye` 项目的核心优化。原 `ciye` 文件夹未参与后续开发，优化均在 `Ciye_pro` 中完成。

## 一、复习调度优化

新增：

- `server/scheduler.py`
- `server/progress_service.py`

主要变化：

- 今日队列生成从 `server/app.py` 中抽出，集中到 `scheduler.py`。
- 生成今日队列前自动补齐当前用户当前词书缺失的 `progress`。
- 复习词不再因为出现在其他日期的 `studied_ids` 中被排除。
- 复习判断统一为：
  - `due_date <= today`
  - 或保持率低于阈值
- 今日队列仍保持原返回结构：
  - `reviews`
  - `new_words`
  - `daily_new_limit`
  - `active_book_id`

## 二、记忆模型优化

`progress` 表新增迁移字段：

- `review_count`
- `lapse_count`
- `difficulty`
- `first_seen_at`
- `last_grade`

反馈按钮规则调整：

| 反馈 | 新逻辑 |
|---|---|
| 不认识 | 降低记忆强度，增加遗忘次数，明天复习，加入错词 |
| 模糊 | 小幅增强，近期复习 |
| 认识 | 稳定增强，数日后复习 |
| 很熟 | 大幅增强，更久后复习 |

`known` 和 `easy` 不再使用几乎相同的调度效果。

## 三、拼写测试闭环

拼写测试现在接入学习模型：

- 拼错：按 `forgot` 处理，写入事件，加入错词，提前复习。
- 拼对：按 `known` 处理，写入事件，提高记忆强度。
- “今日学过的词”只抽今日已完成单词，不再抽今日队列里的未学词。
- “全部词”只抽已学词，不再抽完全 `new` 的词。

## 四、重置逻辑优化

`reset-today` 不再把所有 `due_date = today` 的词重置成新词，避免误伤历史复习词。

现在只重置今天首次引入的新词，并清理当天 session 与事件。

词书重置同步清空新增的记忆模型字段：

- `memory_strength`
- `review_count`
- `lapse_count`
- `difficulty`
- `first_seen_at`
- `last_grade`
- `is_wrong`

## 五、前端保持外观但修正行为

涉及：

- `src/components/StudyCard.vue`
- `src/components/EbbinghausPanel.vue`

调整：

- 反馈按钮提示文案与新算法一致。
- 队列前进时会跳过所有已完成词，而不是只跳过开头的已完成词。
- 今日完成数改为真实 `studied_today` 数量。
- 遗忘曲线待复习文案改为“到期复习或保持率低于 60%”。

视觉布局、颜色、风格没有重做。

## 六、构建优化

## 八、第二轮功能增强

新增：

- 反馈撤销
- 未来 7 天复习预测
- 学习负荷提示
- 错词康复机制

### 1. 反馈撤销

新增表：

- `progress_snapshots`

新增接口：

- `POST /api/progress/undo`

机制：

- 每次学习反馈前保存一份 `progress` 快照。
- 同时保存今日 session 的 `studied_ids`。
- 撤销时恢复 progress，恢复 session，并删除对应事件。

前端：

- 学习卡片反馈后会显示“撤销”按钮。

### 2. 未来 7 天复习预测

新增接口：

- `GET /api/review-forecast`

返回未来 7 天每天到期复习数量。

前端：

- 学习统计页新增“未来 7 天复习预测”卡片。

### 3. 学习负荷提示

`/api/today` 新增：

- `review_load`

当复习词较多时，后端会自动减少或暂停新词，并在今日计划卡片中提示。

### 4. 错词康复机制

规则：

- 错词连续两次正向反馈后自动移出错词本。
- 正向反馈包括 `known` 和 `easy`。

错词本新增展示：

- 遗忘次数
- 下次复习日期
- 康复提示
