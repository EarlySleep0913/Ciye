# 功能清单

## 1. 用户系统

### 1.1 登录/注册
- 书卷展开式登录页面
- Token 认证（Bearer Header）
- 401 自动跳转登录

### 1.2 权限管理
- **管理员**：全部功能 + 用户管理 + AI 配置
- **普通用户**：学习功能，无设置页面

### 1.3 用户管理（管理员）
- 查看所有用户列表
- 设置/取消管理员
- 删除用户

---

## 2. 词书管理

### 2.1 书架展示
- 3D 书籍视觉效果（书脊、封面、页面）
- 每本书显示：总词数、新词数、学习中、已掌握
- 进度条显示掌握百分比

### 2.2 词书操作
- 创建词书（手动输入 CSV 文本）
- 预览词书内容（分页浏览）
- 编辑单词（释义、定义、例句、音标）
- 删除单词
- 删除词书
- 切换当前学习词书
- 重置词书学习进度

### 2.3 导入功能
- CSV/TSV/纯文本导入
- 自动分隔符检测
- AI 提示词模板复制（可粘贴到外部 AI 整理后再导入）

---

## 3. 学习系统

### 3.1 今日学习
- 每日新词 + 复习词混合队列
- 可配置每日新词数量（3-150）
- 复习优先（艾宾浩斯到期词排在前面）
- 动态补充新到期的复习词

### 3.2 学习卡片
- 显示：单词、音标、发音、中文释义、英文释义、例句、配图
- 「翻开释义」交互
- 四级反馈：不认识 / 模糊 / 认识 / 很熟
- 每个反馈影响记忆强度和下次复习时间

### 3.3 拼写测试
- 随机抽取单词进行拼写测试
- 正确/错误动画反馈
- 错词自动加入错词本
- 成绩统计

### 3.4 错词本
- 自动收集拼写错误的单词
- 可手动移除
- 支持发音朗读

### 3.5 收藏夹
- 学习过程中可收藏单词
- 独立列表查看

---

## 4. 艾宾浩斯遗忘曲线

### 4.1 记忆总览
- 平均保持率
- 即将遗忘词数
- 记忆牢固词数
- 已学习总数

### 4.2 记忆强度分布
- 牢固（S≥4）
- 中等（2≤S<4）
- 薄弱（S<2）

### 4.3 待复习列表
- 保持率低于 60% 的词
- 按保持率排序（最低优先）
- 点击可查看单词遗忘曲线详情

### 4.4 遗忘曲线可视化
- 不同记忆强度的标准遗忘曲线
- 单词级别遗忘曲线（带复习阈值线）
- 学习历史记录

---

## 5. 学习统计

### 5.1 数据图表
- 每日学习量柱状图
- 掌握程度饼图
- 学习趋势折线图

### 5.2 学习打卡热力图
- GitHub 风格热力图
- 按年份查看
- 活跃天数和总学习次数统计

---

## 6. AI 功能

### 6.1 AI 助手（BingBing）
- 悬浮可拖拽按钮（GIF 动画）
- 可调整大小的对话框
- 内置英语教师提示词
- 对话历史按用户隔离保存
- 使用 DeepSeek-V4-Flash 模型

### 6.2 AI 对话测试
- 支持多模型切换（Kimi-K2.6 / DeepSeek-V4-Flash）
- 支持 OpenAI 和 Anthropic 两种 API 格式
- 实时对话测试

### 6.3 AI 词书生成
- 输入文本 → AI 整理为标准 CSV
- 固定使用 Kimi-K2.6 模型

---

## 7. 设置

### 7.1 日期模拟
- 调整虚拟日期（前一天/后一天）
- 测试复习调度

### 7.2 学习重置
- 重置今日学习进度
- 重置指定词书全部进度

### 7.3 Pexels 配置
- 输入 API Key 为单词配图

### 7.4 AI 配置
- API URL / Key / Model / Format 设置
- 支持 OpenAI 兼容和 Anthropic Messages 格式

### 7.5 AI 助手大小调整
- 滑块调整悬浮助手图标大小（60-200px）

---

## 8. PDF 词表

### 8.1 每日词表
- 按天展示 PDF 中的单词
- 标记已认识/不认识
- 朗读发音

---

## 9. 全局功能

### 9.1 单词查询
- 点击任意单词弹出查询面板
- 显示音标、释义、定义、例句、配图
- 支持发音朗读

### 9.2 导航栏
- 侧边栏导航
- 根据角色显示/隐藏功能入口
- AI 助手快速入口（重置位置并打开）
