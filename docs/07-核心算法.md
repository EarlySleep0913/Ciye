# 核心算法

## 艾宾浩斯遗忘曲线

### 基本公式

```
R = e^(-t/S)
```

- **R** — 记忆保持率（0~1）
- **t** — 距上次学习的天数
- **S** — 记忆强度（越大遗忘越慢）
- **e** — 自然常数 ≈ 2.718

### 记忆强度变化

每次学习反馈后更新记忆强度 S：

| 反馈 | S 变化 | 说明 |
|------|--------|------|
| forgot（不认识） | S = max(0.5, S - 0.5) | 记忆减弱 |
| vague（模糊） | S = S + 0.3 | 轻微增强 |
| known（认识） | S = S + 1.0 | 中等增强 |
| easy（很熟） | S = S + 1.0 | 中等增强 |

S 的范围：0.5 ~ 20.0

### 复习时机

当保持率 R < 60%（阈值）时，该词进入复习队列。

### 复习间隔计算

```
interval = S × ln(1/threshold)
         = S × ln(1/0.6)
         = S × 0.51 天
```

| S 值 | 复习间隔 |
|------|----------|
| 1.0 | 0.5 天 |
| 2.0 | 1.0 天 |
| 4.0 | 2.0 天 |
| 7.0 | 3.6 天 |
| 10.0 | 5.1 天 |

### 保持率示例

| S=1.0, t=1天 | R = e^(-1/1) = 0.37 (37%) |
| S=2.0, t=1天 | R = e^(-1/2) = 0.61 (61%) |
| S=4.0, t=2天 | R = e^(-2/4) = 0.61 (61%) |
| S=1.0, t=0天 | R = 1.0 (100%) |

## 每日词单生成算法

### 流程

1. 查询所有有进度的单词
2. 分为两组：
   - **复习词**：status ≠ 'new' 且 R < 60%
   - **新词**：status = 'new'
3. 复习词按 R 升序排列（最需要复习的排前面）
4. 组合：复习词（最多50个）+ 新词（按 daily_new_limit）
5. 存入 daily_session 表

### 动态补充

每次请求 `/api/today` 时，检查是否有新的复习词（不在当前队列中）：
- 扫描所有 status ≠ 'new' 的词
- 计算当前 R 值
- R < 60% 且不在 word_ids 中 → 插入队列最前面
- 更新 daily_session

## 数据来源链

### 单词富化（enrich_word）

```
原始单词
    ↓
ECDICT（本地 SQLite）→ translation, phonetic
    ↓
Free Dictionary API → definition, example, audio_url
    ↓
Pexels API → image_url
    ↓
返回完整单词数据
```

### 例句清理（_clean_example）

过滤掉 CSV 数据中的模板例句：
- "I need to remember the word X"
- "I want to remember the word X"

只有 Free Dictionary API 返回的真实例句才保留。

## 前端动画系统

### 滚动显现（v-reveal）

使用 IntersectionObserver：
- 进入视口（threshold 0.1）时添加 `.visible` 类
- CSS transform 从 translateY/translateX/scale(0.8) 过渡到正常
- 一次性触发（unobserve）

### 光标追踪（v-spotlight）

- mousemove 事件设置 CSS 变量 `--mx`, `--my`
- `::before` 伪元素用 radial-gradient 追踪光标
- 边缘老化效果（`::after` 伪元素）

### 弹簧动画

```css
cubic-bezier(0.34, 1.56, 0.64, 1)  /* 弹性回弹 */
cubic-bezier(0.16, 1, 0.3, 1)      /* 平滑减速 */
```

### 卡片交错入场

- CSS 变量 `--i` 控制延迟
- `animation-delay: calc(var(--i) * 60ms)`
