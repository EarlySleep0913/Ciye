# AI 集成

## 概述

系统集成了多个 AI 功能，使用 SiliconFlow 平台（兼容 OpenAI 和 Anthropic API 格式）。

## AI 模型

| 模型 | 用途 | 特点 |
|------|------|------|
| Pro/moonshotai/Kimi-K2.6 | 词书导入解析 | 固定使用 |
| deepseek-ai/DeepSeek-V4-Flash | AI 助手对话 | 通用对话 |

## API 格式支持

### OpenAI 兼容格式

```json
// 请求
{
  "model": "model-name",
  "messages": [{"role": "user", "content": "..."}],
  "temperature": 0.7,
  "max_tokens": 2048
}
// Header: Authorization: Bearer sk-xxx

// 响应
{ "choices": [{ "message": { "content": "回复内容" } }] }
```

### Anthropic Messages 格式

```json
// 请求
{
  "model": "model-name",
  "max_tokens": 2048,
  "messages": [{"role": "user", "content": "..."}]
}
// Header: x-api-key: sk-xxx, anthropic-version: 2023-06-01

// 响应（可能包含 thinking + text 两种 block）
{ "content": [
    {"type": "thinking", "thinking": "..."},
    {"type": "text", "text": "回复内容"}
] }
```

## 后端实现

```python
def _call_ai_api(self, api_url, api_key, model, api_format, user_message):
```

功能：
- 自动拼接 endpoint（`/v1/messages` 或 `/v1/chat/completions`）
- gzip 响应自动解压
- 60 秒超时

### 响应解析

```python
# Anthropic 格式：遍历 content blocks 找 type="text"
for block in result.get("content", []):
    if block.get("type") == "text":
        reply = block.get("text", "")
        break

# OpenAI 格式
reply = result["choices"][0]["message"]["content"]
```

## AI 功能模块

### 1. AI 助手 (BingBing)

**接口**：`POST /api/ai/assistant`

**System Prompt**：
- 角色：20年教学经验的英语老师
- 风格：温暖友好、由浅入深、举例丰富
- 语言：始终用中文回答
- 职责：解释单词、讲解语法、纠正错误、鼓励学生

**历史保存**：`ai_chats` 表，按 user_id 隔离

### 2. AI 对话测试

**接口**：`POST /api/ai/chat`

- 可切换模型
- 可切换 API 格式
- 前端提供模型选择器

### 3. AI 词书导入

**接口**：`POST /api/ai/import`

**流程**：
1. 接收文本或文件（txt/docx/pdf）
2. txt：直接读取
3. docx：本地提取 XML 文本
4. pdf：本地提取文本流
5. 发送给 Kimi-K2.6 整理为 CSV
6. 返回 CSV + 建议词书名

**Prompt 模板**：
```
请把我提供的英语单词资料整理成标准 CSV。
要求：
1. 只输出 CSV，不要解释。
2. 表头固定为：word,translation,definition,example
3. word 只保留英文单词或短语，统一小写。
4. translation 写中文释义，definition 写英文释义，example 写一句英文例句。
5. 如果原资料缺少某列，请合理补全。
6. 确保 CSV 格式正确。
7. 在 CSV 之后，另起一行写 BOOK_NAME: 后跟词书名称建议。
```

## 错误处理

- API 调用超时：120 秒
- 前端请求超时：可通过 options.timeout 自定义（默认 15 秒，AI 调用 120 秒）
- gzip 解压：检查 Content-Encoding header 或 magic bytes
- GBK 编码回退：`_read_json` 先尝试 UTF-8，失败回退 GBK
