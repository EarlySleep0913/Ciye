# 词页（CiYe）智能背单词系统 — 需求分析

## 1. 项目背景

### 1.1 项目概述

词页（CiYe）是一款基于艾宾浩斯遗忘曲线的英语词汇学习 Web 应用，面向英语学习者，提供科学的间隔重复记忆方案。系统采用文学风格的界面设计，融合现代 Web 技术与 AI 辅助功能，帮助用户高效、愉悦地记忆英语单词。

### 1.2 项目目标

- 实现基于艾宾浩斯遗忘曲线的智能复习调度
- 提供多词书管理与灵活的单词导入机制
- 集成 AI 辅助功能，提升学习体验
- 实现多用户数据隔离，支持多人共用
- 打造文学质感的视觉风格，增强学习沉浸感

### 1.3 目标用户

- 英语学习者（大学生、考研、四六级、雅思备考等）
- 需要系统化背单词的用户
- 希望有 AI 辅助答疑的学习者

| 编号 | 需求描述 | 优先级 |

| L-01 | 系统每日生成学习队列，包含新词和需要复习的词 | 高 |

#### 2.3.2 学习卡片

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| L-06 | 学习卡片展示单词、音标、中文释义、英文释义、例句 | 高 |
| L-07 | 支持点击播放单词发音（API 音频优先，浏览器 TTS 兜底） | 高 |
| L-08 | 默认隐藏释义，用户先回忆再点击「翻开释义」查看 | 高 |

#### 2.3.3 反馈机制

| 反馈 | 记忆强度变化 | 复习间隔 |
|------|-------------|----------|
| 不认识 | S = max(0.5, S - 0.5) | 约 0.5 天 |
| 模糊 | S = S + 0.3 | 约 1-2 天 |
| 认识 | S = S + 1.0 | 约 2-5 天 |
| 很熟 | S = S + 1.0 | 约 5-7 天 |

## 3. 非功能性需求

### 3.1 性能需求

| 编号 | 需求描述 |
|------|----------|
| N-01 | 页面加载时间不超过 3 秒 |
| N-02 | API 请求超时时间 15 秒（AI 请求 120 秒） |
| N-03 | 前端请求自动重试 3 次，递增延迟 |

### 3.2 安全需求

| 编号 | 需求描述 |
|------|----------|
| N-04 | 密码使用 SHA256 + 固定盐进行哈希存储 |
| N-05 | 使用 Token 认证，Token 存储于服务端 sessions 表 |
| N-06 | 用户数据通过 user_id 完全隔离 |
| N-07 | 管理员功能接口进行角色校验 |

### 3.3 兼容性需求

| 编号 | 需求描述 |
|------|----------|
| N-08 | 支持主流现代浏览器（Chrome、Edge、Firefox） |
| N-09 | 响应式布局，适配 720px 以上屏幕 |

### 3.4 可维护性需求

| 编号 | 需求描述 |
|------|----------|
| N-10 | 后端零外部依赖，仅使用 Python 标准库 |
| N-11 | 前端使用 Vue 3 Composition API，组件化开发 |

## 4. 数据需求

### 4.1 数据实体

| 实体 | 说明 |
|------|------|
| 用户 (users) | 系统注册用户 |
| 词书 (books) | 用户创建的单词集合 |
| 单词 (words) | 词书中的具体单词 |
| 学习进度 (progress) | 用户对每个单词的学习状态 |
| 学习事件 (events) | 每次学习反馈的记录 |
| 每日会话 (daily_session) | 每日学习队列的持久化 |
| 设置 (settings) | 用户/全局配置项 |
| AI 对话 (ai_chats) | AI 助手对话历史 |
| PDF 词表 (pdf_words) | 导入的 PDF 单词数据 |

### 4.2 数据量估算

| 数据 | 预估规模 |
|------|----------|
| 单个词书 | 500-5000 词 |
| 用户词书数 | 1-10 本 |
| 每日学习事件 | 15-50 条 |
| 年度学习事件 | 5000-15000 条 |
