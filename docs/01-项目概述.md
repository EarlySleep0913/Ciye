# 词页 (CiYe) — 项目概述

## 项目简介

词页是一款文学风格的英语词汇学习 Web 应用，采用间隔重复（Spaced Repetition）和艾宾浩斯遗忘曲线算法，帮助用户高效记忆英语单词。

## 核心特色

- **艾宾浩斯遗忘曲线驱动** — 基于 R = e^(-t/S) 公式智能安排复习时间
- **多用户数据隔离** — 每个用户的学习进度、词书、设置完全独立
- **AI 辅助学习** — 集成 AI 对话助手（BingBing）和 AI 词书导入
- **文学风格 UI** — 纸张质感、宋体/衬线字体、暖色调设计系统
- **零外部依赖后端** — Python 标准库实现，SQLite 数据库

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | Vue 3 + Composition API |
| 构建工具 | Vite 6 |
| UI 组件库 | Lucide Vue Next（图标） |
| 图表库 | Chart.js + vue-chartjs |
| 后端语言 | Python 3（标准库） |
| 数据库 | SQLite（WAL 模式） |
| HTTP 服务器 | ThreadingHTTPServer |
