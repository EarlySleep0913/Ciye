## 前端架构

### 目录结构

```
src/
├── main.js                    # 入口，注册全局指令
├── App.vue                    # 根组件，路由/鉴权
├── composables/
│   ├── useApi.js              # HTTP 请求封装（重试/超时/Token）
│   └── useAudio.js            # 发音播放（API → TTS 兜底）
├── components/
│   ├── LoginPage.vue          # 登录页
│   ├── NavRail.vue            # 侧边导航栏
│   ├── StudyCard.vue          # 学习卡片主界面
│   ├── BookShelf.vue          # 书架
│   ├── BookPreview.vue        # 词书预览/编辑
│   ├── SpellingTest.vue       # 拼写测试
│   ├── WrongWords.vue         # 错词本
│   ├── Favorites.vue          # 收藏夹
│   ├── EbbinghausPanel.vue    # 遗忘曲线
│   ├── StatsPanel.vue         # 学习统计
│   ├── Heatmap.vue            # 打卡热力图
│   ├── SettingsPanel.vue      # 设置
│   ├── UserManager.vue        # 用户管理
│   ├── AiAssistant.vue        # AI 悬浮助手
│   ├── LookupPopover.vue      # 单词查询弹窗

└── styles/
    └── main.css               # 全局样式 + 设计系统
```

### 组件通信

- **Props 向下** — App 向子组件传递 api、settings、books 等
- **Events 向上** — 子组件通过 emit 通知父组件刷新数据
- **全局状态** — 通过 ref/reactive 在 App 层管理

### 关键技术

| 技术 | 用途 |
|------|------|
| Vue 3 Composition API | 组合式 API，更好的逻辑复用 |
| `<script setup>` | 简化组件语法 |
| `reactive()` | 包装队列项实现直接属性修改触发更新 |
| `computed()` | 派生状态（队列、统计等） |
| `watch()` | 监听数据变化自动更新 |
| `Teleport` | 弹窗/对话框渲染到 body |
| `Transition` | 组件进入/离开动画 |
| 自定义指令 | v-reveal（滚动显现）、v-spotlight（光标追踪） |

## 后端架构

### 目录结构

```
server/
├── __init__.py
├── app.py           # 主路由（CiYeHandler）
├── auth.py          # 登录/注册/用户管理
├── db.py            # 数据库初始化/连接池/Schema
├── ebbinghaus.py    # 遗忘曲线算法
├── dict.py          # ECDICT + Free Dictionary 查词
└── pexels.py        # Pexels 图片搜索
```

### 请求处理流程

```
HTTP Request
    ↓
do_GET / do_POST / do_DELETE
    ↓
_require_user() → Token 验证
    ↓
路由匹配 → Handler 方法
    ↓
SQL 操作（线程本地连接）
    ↓
_json_response() → 响应
```

### 线程模型

- 使用 `ThreadingHTTPServer`，每个请求一个线程
- 线程本地 SQLite 连接（`threading.local()`）
- WAL 模式支持并发读

### 中间件功能

- Token 鉴权（Bearer Header）
- 静态文件服务（public/ 目录）
- CORS 处理（开发模式 Vite 代理）
- 错误捕获（try/except 包裹所有路由）
